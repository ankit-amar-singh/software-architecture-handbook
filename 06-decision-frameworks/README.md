# 📊 Module 06: Architecture Decision Frameworks

This module provides reusable tools, Markdown templates, decision matrices, and flowcharts for making and documenting high-stakes technical architectural decisions.

---

## 📁 Included Decision Tools

1. 📝 **[ADR Templates & Samples](./adr-templates)**: Architectural Decision Records (ADRs) capturing decision rationale, context, and consequences.
2. 📊 **[Architecture Comparison Matrix](./architecture-comparison-matrix.md)**: Multi-dimensional evaluation matrix comparing Monolith, Microservices, EDA, Serverless, and Monorepo styles.
3. 🌳 **[Interactive Decision Trees](./decision-trees)**: Visual flowcharts for selecting architectural paradigms.
